    Class Transform

    Represents the position, rotation, and scale of an object in 3D space. It handles hierarchical transformations (parent-child relationships) and calculates the corresponding model matrix for rendering.

    Remarks

    Transformations are calculated lazily. The model matrix and world-space properties are only recomputed when they are accessed and the transform is marked as "dirty".
