## 1. Overview & Purpose
| Component | Source File |
| :--- | :--- |
| LightsUBO | /core/render/lights-ubo.ts |

This component is responsible for managing and serializing light data into a structure compatible with WebGL Uniform Buffer Objects (UBOs). It defines the exact memory layout (`LIGHTS_LAYOUT`) required by the shader (`functions/light.frag`) to efficiently pass multiple light parameters (position, color, attenuation, etc.) from the CPU to the GPU in a single buffer.

It serves as a critical data serialization layer within the rendering pipeline. It takes a collection of active lights, packs their properties according to the `std140` layout, and updates a GPU buffer (`LightsUBO`) bound at a specific binding point, allowing shaders to access all necessary lighting information for the current frame.

## 2. Public API & Interfaces
| Entity | Type | Description |
| :--- | :--- | :--- |
| `MAX_DIRECTIONAL_LIGHTS` | Constant | Maximum number of directional lights supported in the UBO. |
| `MAX_POINT_LIGHTS` | Constant | Maximum number of point lights supported in the UBO. |
| `MAX_SPOT_LIGHTS` | Constant | Maximum number of spot lights supported in the UBO. |
| `LIGHTS_BINDING_POINT` | Constant | The GL binding point index where the UBO is bound (1). |
| `LIGHTS_LAYOUT` | Constant | An object defining the memory offsets and sizes for all light parameters in the UBO. |
| `packLights` | Function | Serializes an array of `Light` objects and optional shadow slot mappings into a `Float32Array` conforming to `LIGHTS_LAYOUT`. |
| `LightsUBO` | Class | Manages the creation, updating, and disposal of the WebGL buffer containing light data. |
| `LightsUBO.update` | Method | Recalculates and uploads the current light data to the underlying WebGL buffer. |
| `LightsUBO.dispose` | Method | Releases the underlying WebGL buffer resource. |

## 3. Implementation Details & Side Effects
- **Core Logic:** The `packLights` function iterates over filtered lists of directional, point, and spot lights. It maps properties like position, color, and attenuation into the predefined slots of `LIGHTS_LAYOUT`. The `LightsUBO` class handles the boilerplate of creating and updating the `WebGLBuffer` using `gl.bufferSubData` to reflect the data generated by `packLights`.
- **Side Effects:** The `LightsUBO` class directly interacts with the WebGL rendering context (`gl`), creating, binding, and updating `WebGLBuffer` objects.
- **Error Handling:** The `LightsUBO` constructor uses the non-null assertion operator (`!`) on `gl.createBuffer()`, implying that buffer creation failure is not explicitly handled but relies on the context being valid.
